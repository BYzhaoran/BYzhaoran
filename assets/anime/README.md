## 使用注意

- CC0 仅表示上述仓库对其声明覆盖的素材放弃/许可相关权利；不代表其他同名或转载素材自动获得相同授权。
- 如果把这些文件发布到项目外部，建议同时保留本说明文件，尤其是来源地址和许可证记录。
- `project-cordon-sprites` 的仓库整体标识为 CC0，但其具体素材可能来自社区贡献；正式商业发布前可再次查阅对应提交和作者说明。
